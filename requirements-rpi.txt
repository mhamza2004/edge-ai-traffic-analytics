# Raspberry Pi 4/5 (64-bit Raspberry Pi OS) deployment requirements.
# Install system packages first, then these via pip.
#
#   sudo apt update && sudo apt install -y python3-opencv python3-picamera2 mosquitto mosquitto-clients
#   pip install -r requirements-rpi.txt --break-system-packages
#
# Notes:
# - opencv-python-headless is used instead of opencv-python (no GUI deps needed on a headless Pi).
# - picamera2 ships as a system package on Raspberry Pi OS (apt), not pip -- do not pip install it.
# - For NCNN export/inference, `ncnn` wheels install cleanly on 64-bit Pi OS via pip.
# - Skip ultralytics' torch dependency for pure-inference edge deployments by exporting to
#   NCNN or TFLite first (scripts/export_edge_model.py) on a dev machine, then deploying just
#   the exported model + this requirements file to the Pi.
